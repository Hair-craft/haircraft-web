# Fonts for generated share images

The share images (`opengraph-image.tsx`) are drawn by `next/og`, which can't use the web fonts `next/font` downloads (WOFF2), so the two brand fonts are kept here as WOFF:

- `CormorantGaramond-Medium.woff`: Cormorant Garamond 500, by Christian Thalmann (Catharsis Fonts)
- `Geist-Medium.woff`: Geist 500, by Vercel

Both are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling them with the site. They were downloaded from Google Fonts.
